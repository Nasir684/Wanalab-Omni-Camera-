### 🛠️ How to Use
1. Open Live Demo on Android Chrome
2. Allow Camera
3. Tap modes at top
4. Bottom bar: NIGHT GOD / AI DETECT / THERMAL / IP CAM / CAPTURE
5. Export from /export.html
