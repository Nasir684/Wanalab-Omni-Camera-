### How to Use
1. Open Test Link in **Chrome** (not WhatsApp) → Allow Camera+Mic
2. 📱 DEVICES (5) → Choose
3. 🔢 COUNT ROI → Draw box → See `Count: X bottles`
4. 🎤 VOICE → Say `Count` or `Ginti karo` or `Bill banao`
5. 🧾 TAP BILL → Add item → BILL PDF
6. 📸 → Manual Crop → Filters → Export
